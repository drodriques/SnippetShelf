# App screenshots

`appearance-overview.png` pairs actual app captures in Light (left) and Dark
(right), with identical content and panel sizes. The individual captures are
`light-mode.png` and `dark-mode.png`. Only window chrome was cropped; app content
was not redrawn or generated. The overview adds labels, a neutral canvas and a
subtle border, then resizes the captures proportionally.

`sample-library.json` is a fictional demonstration library: six snippets, five
tags and no saved System favorites. Names, commands and paths are invented
examples. It is a documentation fixture, not app startup/default user data.
