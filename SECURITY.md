# Security policy

Please report suspected security vulnerabilities privately using
[Report a vulnerability](https://github.com/drodriques/SnippetShelf/security/advisories/new)
(requires a GitHub account). Do not post vulnerability details in public issues.

Include the SnippetShelf and macOS versions, steps to reproduce, and potential
impact. Use a minimal example with fictional data; omit passwords, tokens, and
private snippets.

Reports are reviewed by the maintainer. Please allow time to investigate and
coordinate disclosure before publishing details.

For ordinary bugs and feature requests, use
[Issues](https://github.com/drodriques/SnippetShelf/issues).
